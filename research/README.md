# 裁判文书数据分析（进行中）

> 目标：把"期权能不能拿回来"这个问题，从个案叙事变成可验证的数据。
>
> **状态：初步结果，尚未发布。** 数据口径和偏差修正仍在进行。

## 为什么做这个

这个仓库现有的内容是**案例驱动**的——四起实名争议，讲清楚机制。它的问题是：读者知道了别人身上发生了什么，但不知道**这在整体上有多普遍、法院整体怎么判**。

数据分析补的就是这一块。它同时解决三个问题：

1. **可信度**：数据可被复现和引用，比个案叙事更难被质疑；
2. **安全性**：讨论的是总体分布，不是对具体公司的指控，法律敞口显著更低；
3. **稀缺性**：律所内部有这类数据，但不会免费公开。

## 数据来源与方法

**来源**：中国裁判文书网（wenshu.court.gov.cn），登录态下的高级检索。

**核心方法**：读取检索结果页左侧的**分面统计**。分面是网站对全部命中结果的聚合，**不是抽样**，因此不受"列表最多显示前 600 条"这一限制的影响。

**核心口径**：

| 代号 | 定义 | 命中数 |
|---|---|---|
| `P_equity_labor` | 案由 = 劳动争议、人事争议 **且** 全文含"股权激励" | 1,712 |
| `B_labor_all` | 案由 = 劳动争议、人事争议（基线） | 4,227,295 |

选择"案由 + 全文关键词"的双重限定，是因为**单纯全文检索噪音过大**：只搜"股权激励"命中 7,284 篇，其中大量是职务发明奖励、专利权属、商业秘密纠纷等仅在文书中提及该词的案件，不能作为统计口径。

## ⚠️ 已知偏差（发布时必须一并呈现）

1. **文书公开率不等于案件量。** 2021 年后裁判文书上网率整体下降，绝对数的年度趋势不可直接解读为"纠纷变多/变少"。
   → **缓解办法**：用"股权激励案件 / 全部劳动争议"的**比值**做趋势，分子分母受同样的公开率影响，比值可以消掉大部分偏差。这是本研究最关键的方法设计。

2. **关键词漏检。** 只写"期权""限制性股票""虚拟股权""持股平台"而未出现"股权激励"四字的案件会被漏掉，因此 1,712 是**下界**。
   → 待办：补跑其他关键词并做并集去重。

3. **文本长度混杂。** 中级法院判决书通常比基层更长更详细，更容易命中关键词，可能**高估**中院占比。
   → 待办：把对比限定在"文书类型 = 判决书"内部重跑一次。

4. **仲裁黑洞。** 劳动争议须先经仲裁，大量案件在仲裁阶段终结，仲裁裁决**完全不公开**。本研究只能覆盖进入诉讼且被公开的部分。
   → 无法修正，只能明确声明。

5. **调解/撤诉不可见。** 以调解或撤诉结案的案件基本不产生可检索的实体裁判文书，因此**任何"胜诉率"都不等于"维权成功率"**。
