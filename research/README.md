# 裁判文书数据分析（进行中）

> 目标：把"期权能不能拿回来"这个问题，从个案叙事变成可验证的数据。
>
> **状态：初步结果，尚未发布。** 数据口径和偏差修正仍在进行。

## 为什么做这个

这个仓库现有的内容是**案例驱动**的——四起实名争议，讲清楚机制。它的问题是：读者知道了别人身上发生了什么，但不知道**这在整体上有多普遍、法院整体怎么判**。

数据分析补的就是这一块。它同时解决三个问题：

1. **可信度**：数据可被复现和引用，比个案叙事更难被质疑；
2. **安全性**：讨论的是总体分布，不是对具体公司的指控，法律敞口显著更低；
3. **稀缺性**：律所内部有这类数据，但不会免费公开。

## 数据来源与方法

**来源**：中国裁判文书网（wenshu.court.gov.cn），登录态下的高级检索。

**核心方法**：读取检索结果页左侧的**分面统计**。分面是网站对全部命中结果的聚合，**不是抽样**，因此不受"列表最多显示前 600 条"这一限制的影响。

**核心口径**：

全部限定 **案由 = 劳动争议、人事争议** 且 **文书类型 = 判决书**（分子分母同口径）：

| 集合 | 命中数 |
|---|---|
| 基线：劳动争议判决书 | 2,029,038 |
| 含「股权激励」 | 1,576 |
| 含「期权」 | 1,806 |
| 交集 | 271 |
| **并集（容斥）** | **3,111** |

**为什么限定判决书**：裁定书大量是立案、管辖类程序性文书，高度集中在基层法院，会污染审级对比。第一轮未限定时算出的"上诉率 1.88 倍"是错的，校正后是 1.28 倍。

**为什么要做并集**：「股权激励」与「期权」两个关键词的重叠率只有 17.2%，单关键词检索会系统性低估规模约一半。检索页的「全文检索」条件可叠加且叠加为 AND，因此可直接取交集、用容斥原理算并集。

选择"案由 + 全文关键词"的双重限定，是因为**单纯全文检索噪音过大**：只搜"股权激励"命中 7,284 篇，其中大量是职务发明奖励、专利权属、商业秘密纠纷等仅在文书中提及该词的案件，不能作为统计口径。

## ⚠️ 已知偏差（发布时必须一并呈现）

1. **文书公开率不等于案件量。** 2021 年后裁判文书上网率整体下降，绝对数的年度趋势不可直接解读为"纠纷变多/变少"。
   → **缓解办法**：用"股权激励案件 / 全部劳动争议"的**比值**做趋势，分子分母受同样的公开率影响，比值可以消掉大部分偏差。这是本研究最关键的方法设计。

2. **关键词漏检。** ✅ 已部分处理：已补「期权」并用容斥算出并集 3,111。仍可能漏掉只写"虚拟股权""持股平台""股票增值权"的案件，因此 3,111 仍是**下界**。
   → 另一方向的偏差：「期权」一词也会命中少量无关案件（噪音），因此真实值介于 1,576 与 3,111 之间。

3. **文本长度混杂。** ✅ 已处理：对比已限定在"文书类型 = 判决书"内部重跑。残余偏差仍存在（中院判决书通常更长），故 1.28x 应视为上界。

4. **仲裁黑洞。** 劳动争议须先经仲裁，大量案件在仲裁阶段终结，仲裁裁决**完全不公开**。本研究只能覆盖进入诉讼且被公开的部分。
   → 无法修正，只能明确声明。

5. **调解/撤诉不可见。** 以调解或撤诉结案的案件基本不产生可检索的实体裁判文书，因此**任何"胜诉率"都不等于"维权成功率"**。

6. **🔴 串案与重复收录。** 全样本枚举后程序化统计：510 条记录中，**11 个案号被重复收录（15 条冗余）**，另有 **19 个串案簇（95 条冗余，最大一簇 36 件）**。去重折叠后 ≈ **404 个独立纠纷，膨胀率约 26%**。**分面统计无法发现这一点**，任何按地域/年份的排名在去重前都不可用。详见 [notes/dedup-findings.md](notes/dedup-findings.md) 与 [notes/party-identity.md](notes/party-identity.md)。

7. **🔴 原告身份必须先分开。** 一审中约 **23.8%** 是公司起诉员工（公司对仲裁裁决不服）。因此"原告败诉"在四分之一的案件里意味着**员工赢了**。任何不区分原被告身份的胜诉率，方向可能是反的。
